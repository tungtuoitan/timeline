# Fix: Tag Slug Duplicate Key Error

## Problem
When creating a new tag via `POST /api/workspace/{workspaceId}/items` with payload:
```json
{
    "parentTagId": 137,
    "childType": "tag",
    "tagName": "test1",
    "color": "#1976D2",
    "sortOrder": 0
}
```

The API returned **500 Internal Server Error** with the following database error:
```
Cannot insert duplicate key row in object 'dbo.tags' with unique index 'UQ_tags_user_slug'.
The duplicate key value is (1, ).
```

## Root Cause
1. The `Tag` model constructor was setting `Slug = string.Empty` by default
2. When EF Core inserted a new tag, it sent `slug = ''` (empty string) to the database
3. The unique constraint `UQ_tags_user_slug` (on `user_id` + `slug`) was violated because multiple tags existed with `user_id=1` and `slug=''`

The code comments indicated that slug should be "generated by trigger", but:
- No database trigger actually existed to generate slugs
- EF Core was sending empty string instead of NULL

## Solution
**Generate slug in application code with timestamp suffix to ensure uniqueness:**

### 1. Updated `Tag.cs` Model
- Changed `Slug` property from `string` to `string?` (nullable)
- Removed `Slug = string.Empty` from constructor
- Added comment: "Slug is generated by application code"

### 2. Updated `TagConfiguration.cs`
- Marked Slug as nullable: `.IsRequired(false)`
- Removed `.ValueGeneratedOnAdd()` since we generate in code
- Updated comment: "generated by application code"

### 3. Updated `AddItemToWorkspaceCommandHandler.cs`
- Added `GenerateSlug(string name)` method that:
  - Converts name to lowercase
  - Removes special characters
  - Replaces spaces with hyphens
  - Adds timestamp suffix (e.g., `test1-638653847230000000`)
  - Ensures uniqueness per user
- Updated tag creation to call `Slug = GenerateSlug(request.TagName)`

## Slug Generation Logic
```csharp
private static string GenerateSlug(string name)
{
    // Convert "Test Tag Name" → "test-tag-name-638653847230000000"
    var slug = name.ToLowerInvariant();
    slug = Regex.Replace(slug, @"[^a-z0-9\s-]", "");      // Remove special chars
    slug = Regex.Replace(slug, @"\s+", "-");               // Spaces → hyphens
    slug = Regex.Replace(slug, @"-+", "-");                // Remove consecutive hyphens
    slug = slug.Trim('-');                                 // Trim edges
    slug = $"{slug}-{DateTime.UtcNow.Ticks}";             // Add unique timestamp
    return slug.Substring(0, Math.Min(slug.Length, 255)); // Max 255 chars
}
```
